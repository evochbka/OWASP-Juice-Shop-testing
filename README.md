# QA portfolio - OWASP Juice shop

## О проекте

Тестирование веб-приложения OWASP Juice Shop (тренажер для тестирования безопасности).
Цель: демонстрация навыков функционального тестирования, тестирования безопасности и работы с тестовой документацией.

## Стек и инструменты

- **DevTools** - Console, Network, Application
- **JWT** - анализ токенов
- **Markdown** - документация
- **SQLmap** - проверка SQL-инъекций

## Что сделано

### Фунцкиональное тестирование

- Составлено 3 чек-листа: авторизация, каталог, безопасность
- Написано 18 тест-кейсов в соответствии с проверками, указанными в чек-листах
- Проверены как позитивные, так и негативные данные (валидные и невалидные данные, пустые поля)

### Тестирование безопасности

- Написано 5 тест-кейсов по проверкам, указанным в чек-листе
- Обнаружено 2 потенциальных уявзимости

## Найденные баги

| ID | Заголовок | Критичность | Статус |
|----|-----------|-------------|--------|
| BUG-001 | IDOR в `/rest/basket/{id}` — чтение чужой корзины | Critical | Open |
| BUG-002 | Пароль отображается в открытом виде в Payload | High | Open |
| BUG-003 | Отсутствие авторизации на API корзины | High | Open |

-> Полные баг=репорты с шагами воспроизведения в папке 'bug-reports'

## Итоги тестирования

- **Проверено:** функционал авторизации, каталога, отзывов, частично безопасность
- **Найдено:** 3 уязвимости (1 Critical, 2 High)

## Как воспроизвести

1. Установить OWASP Juice Shop: `docker run -p 3000:3000 bkimminich/juice-shop`
2. Открыть `http://localhost:3000`
3. Для проверки багов — следовать шагам в соответствующих баг-репортах
